# FDE Training · 学员公开库

> 「人人都是 FDE」四周实践课 · FDE Lab
> 本库公开、面向学员。材料随课程进度放入：每课课前准备包课前发，讲过的内容课后归档到对应课次文件夹。内部规划、讲师讲稿、服务器配置不在本库。

## 这门课

四周、每周一次、每次两小时，带着你的真实问题来，每周做出一个能用的东西：

| 课次 | 日期 | 主题 |
|---|---|---|
| 第 1 课 | 2026-12-2 | 做出你的第一个 Skill |
| 第 2 课 | 2026-12-9 | 做出能跑的原型 |
| 第 3 课 | 2026-12-16 | 做出他人能用的 MVP |
| 第 4 课 | 2026-12-23 | 部署变产品 · 发布 |

## 怎么用

1. clone 本库。
2. 每课课前读对应文件夹的「课前准备包」——它是发给你的 AI 工作台的**课前上下文**，交给你的 AI，让它帮你安排要了解的知识和要看的视频。
3. 照「操作单」实操，演示与练习材料在 `materials/`。
4. 你的产品按讲师指引放在自己的文件夹或分支提交。

## 结构

- `day1/` … `day4/`：每课教学包（课前上下文、讲义、Skill、操作单、材料），随进度放入。
- 讲师内部件（讲稿、规划、服务器配置等）不在本库。

## 公开口径

- 进本库的材料均经讲师脱敏放行：不含内网地址、密钥、第三方隐私。
- 不承诺证书、学分、生产上线、商业成功。
