# FDE Training · 学员公开库

> 「人人都是 FDE」四周实践课 · FDE Lab
> **仓库地址：<https://github.com/XJTLU-AOA-TECH/fde-training-learner>**

本库公开、面向学员，是课程材料的**唯一发布处**——不用在群里单独收 markdown，clone 本库即可。材料随课程进度放入：每课课前准备包课前发布，讲过的内容课后归档。讲师内部件（讲稿、规划、服务器配置）不在本库。

## 快速开始

```bash
git clone https://github.com/XJTLU-AOA-TECH/fde-training-learner.git
cd fde-training-learner
```

每课课前：打开对应课次文件夹的「课前准备包.md」，把它交给你的 AI 工作台（Codex／Claude Code／DeepSeek Harness），让 AI 帮你安排课前学习。

## 怎么用课前准备包

它是发给你的 AI 的**课前上下文**，不是讲义。交给 AI，对它说：

> 「这是第 N 课的课前上下文。先问我几个问题判断我的基础，再据此安排：哪些概念我要先了解、按什么顺序、对应看哪些视频；最后检查我的环境是否就绪。」

按 AI 的安排走，照准备清单装好环境，群里回执。
